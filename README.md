# Programación Web

## Actividad 1 - Tema 2: Ejercicios de Desarrollo Web

Este repositorio reúne como evidencia las prácticas desarrolladas a lo largo de la unidad, organizadas y enlazadas a través de una página principal de navegación.

---

### Propósito
El propósito de esta práctica es integrar en un entorno web funcional los ejercicios de maquetación y diseño, aplicando estructura semántica en HTML, estilos visuales en CSS e interactividad básica con JavaScript. Además, se busca llevar el proyecto de un entorno local a producción mediante el despliegue en GitHub Pages, asegurando la correcta vinculación de recursos y rutas relativas.
